# Ders kaynakları

Planlama belgelerindeki PDF atıfları aşağıdaki kaynaklara dayanır. Bu rehber, ekip üyelerinin aynı belgeyi ve sayfa numaralarını bulmasını sağlar. Kaynak PDF'ler planın hazırlandığı yerel çalışma alanındaki `out-of-project-files/` klasöründedir; bu branch'e PDF kopyaları eklenmemiştir.

Ekip üyeleri öğretim elemanlarının sağladığı kaynakları dosya adlarıyla eşleştirebilir. Plan içindeki sayfa numaraları PDF sayfalarını ifade eder. Dersin daha sonraki duyuruları kaynakları değiştirirse ilgili plan ve atıflar birlikte güncellenmelidir.
